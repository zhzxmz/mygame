# RegionSourceCandidate Implementation Decision（Phase 3.1.10 · 最小实现决策清单）

> **文档性质**：**实现决策申请（Implementation Decision Request）**。把纯数据载体落地所需的**类型层批准**整理成可逐条批准的清单；**本轮不写代码、不进入 Phase 3.2**。
>
> **依据（三份已交付报告）**：`Region_Source_Candidate_Field_Freeze_Matrix.md`（3.1.8，`B9893C569A8D9935`）· `Region_Epoch_Ordinal_Clarification.md`（3.1.9，`0C43D567E96F3CFF`）· `Region_Radius_Scale_Decision_Record.md`（3.1.7，`10BDFE56A8D27CE6`）；原始契约与代码行号均已在上述报告中逐一核验，本文件复用同一批引用。
>
> **本轮边界（已遵守）**：只新增本文件；不修改任何现有文档 / 契约 / 代码 / 测试 / 场景 / Prefab；**不实现**任何类型；不进入 Phase 3.2。
>
> **两类必须分开的事项（全文遵守）**：
> **① 已批准的概念结构** = 由设计者已批准或由契约原文确定（§2）；
> **② 建议采用的 C# 类型** = **尚未批准**、需设计者逐条批准（§3/§4）。
> **不得把 ② 当作 ① 陈述。**
>
> **一句话**：**概念结构已定（8 字段 / `Radius` 单字段规范名 / `Epoch`+`Ordinal` 可分别取值）；C# 类型**一个都没有**被契约冻结 → 需批准 `AP-1`–`AP-8` 八条类型决策（其中 `AP-6` 用于解除 3.1.8 的硬阻塞 `H-1`），批准后方可实现"字段 + 只赋值构造 + 值语义"的纯数据载体。**

## §3 逐字段推荐的 C# 类型（**全部为待批准的建议**）

> **重要区分**：下表"推荐类型"列**没有任何一项**是契约冻结的类型；契约冻结的只有**概念与（部分）语义**（见"依据"列的等级）。
> **成员数说明**：若采用下表，类型**成员数 > 8**（`Position` 自身含 3 个 `int` 分量；`Epoch` 槽位含 2 个 `int` 分量），但**概念字段数恒为 8**。

| 字段 | 推荐 C# 类型 | 依据 | 依据等级 | 批准状态 | 未决风险（不影响存储） | 最小替代方案 |
|---|---|---|---|---|---|---|
| **`Kind`** | `int`（整数类别码） | 契约只给"来源类别"与"子类枚举不得由本文档新增"（`RA` **L158**）；权威清单在 `Region_Design.md` §3.2（**L206**–**L241**） | 【契约原文】（语义）+【设计建议】（类型） | **待批准**（`AP-1`） | 类别 ↔ 码映射表缺失 → 值合法性/解释不可判定 | `enum`（需 `Region_Design.md` §3.2 升版本同步登记，代价更高） |
| **`DomainId`** | `int` | `RA` **L159**（指向 §6.4）；`RA10` **L126**（未登记域不得使用）；`PZ10`（`WPC` **L398**"显式整数标识（32 位无符号）"）；`WPC` §6.4 域表 **L415**–**L419** | 【契约原文】（"整数标识"）+【既有同概念代码先例】`RegionIdentity.RegionDomain` 为 `int`（`RegionIdentity.cs` **L37**） | **待批准**（`AP-2`） | 有符号性未明说；域值校验责任与时机未定 | `uint`（更贴合"无符号"字面，但与既有 `int` 不一致） |
| **`Position`** | `WorldCoordinate`（**复用**） | `RA` **L160**"锚点世界坐标；不得是 Chunk 局部坐标"；`WorldCoordinate` 实读：`readonly struct` + `int x/y/z`（**L29**–**L31**）、**不提供坐标换算**（**L15**）、换算权威 `ChunkSize=16`/`world = chunk×16+local`/负数 floor（**L17**） | 【契约原文】（语义）+【既有同概念代码先例】（类型） | **待批准**（`AP-3`） | `CanonicalPosition` 量化（`RA12` **L128**）属采纳链，不属载体 | 新建坐标类型（**违反**"不得第二套坐标语义"的既有纪律） |
| **`Strength`** | `float` | `RA` **L161**"显式标量；范围由 Region 规则声明"；无类型明文 | 【设计建议】+【既有同概念代码先例】（连续量用 `float`：`RegionModifier.cs` **L38**–**L43**） | **待批准**（`AP-4`） | 有效范围未定（属 Region 规则）→ **构造期不做值域校验** | `double`（精度更高、与既有 `float` 惯例不一致）；定点整数（需先定单位） |
| **`Radius`** | `float` | `D-RS-1`/`D-RS-2`（3.1.7 **L21**/**L22**）；原文该行"影响尺度；世界单位；必须 `> 0`"（`RA` **L162**）；`RA51` **L232**（`Extent` 由其加形状标识决定）；`RA72` **L294** | 【契约原文】（`> 0` 与用途）+【设计建议】（类型） | **待批准**（`AP-5`） | 单位（"世界单位"与"体素单位"的关系）、**最大值**、量化方式均未定 | 整数（若设计者裁定"世界单位 = 体素整数"） |
| **`Epoch`** 槽位 | **两个独立 `int` 分量**：`Epoch` + `Ordinal` | `HE1` **L160**（`Epoch`（纪元段）+ `Ordinal`（段内序位））；`WPC` **L214**（`Epoch`：整数 ID（int））/ **L235**（`Ordinal`：整数）/ **L635**/**L636**（附录 B 序 10/11 独立登记）；`RA37` **L203** / `RA44` **L215**（键含两分量） | 【契约原文】（两个分量与类型均有依据）+【设计建议】（"槽位内两成员"这一表示） | **待批准**（`AP-6`，**解除 3.1.8 硬阻塞 `H-1`**） | 位宽/有符号性；`EpochCount`/`OrdinalMax` 读取方式；`RA11` **L127** 保留值编码 | 单个复合值类型（内含两个 `int`；语义等价，需多一个类型工件） |
| **`OriginRef`** | 不透明 `long` | `RA` **L164**（原因引用；**必须可解析**）；句柄先例：`RegionIdentity.RegionSource`（`long`，`RegionIdentity.cs` **L38**） | 【契约原文】（字段语义）+【既有同概念代码先例】（句柄形态） | **待批准**（`AP-7`） | 解析目标/责任/生命周期/失效语义未定义 → **只影响运行时** | 复合引用类型（需新增共享引用词汇表 → 新增概念） |
| **`ReasonChainRef`** | **独立**的不透明 `long` | `RA` **L165**（可解释链引用；供 `WorldQuery_Design.md` §6）；句柄先例：`RegionContext.RegionSourceReference`（`long`，**L42**） | 【契约原文】（字段语义）+【既有同概念代码先例】 | **待批准**（`AP-8`） | 同上 + 与 `OriginRef` 的关系未定义（**不得默认同目标**） | 与 `OriginRef` 共用一个类型（**风险**：暗示同一引用体系，原文未支持） |
