# WorldQuery Architecture Contract V1

> **文档性质**：**架构契约规范（Architecture Contract）**。本文档只建立 **WorldQuery 的架构契约**，**不实现任何代码**。
> **仅允许新增** `Specifications/World/WorldQuery_Architecture_Contract.md`（本文件）。
> **禁止**：修改任何已有 `.md`；修改 `Assets/**`；新建 `.cs`；新增接口/class；新增参数；新增 `VoxelType`；新增因果边。
>
> **核心定位**：
>
> > **WorldQuery = 世界解释访问层（Explanation Access Layer）。**
> > **不生成世界、不修改世界、不缓存世界真值**；只负责向**工具 / UI / 调试 / AI / 玩家解释系统**提供**统一查询接口**（语义层）。
>
> | WorldQuery 不拥有 | 说明 |
> |---|---|
> | WorldState | 参数不属 WorldQuery（Owner = WorldState 层） |
> | Region | 区域采纳/修正不属 WorldQuery（Owner = Region 层） |
> | Biome | 分类不属 WorldQuery（Owner = Biome 层） |
> | Geology | 地质解释不属 WorldQuery（Owner = Geology 层） |
> | Resource | 资源判定不属 WorldQuery（Owner = Resource 层） |
> | Ecology | 生态候选不属 WorldQuery（Owner = Ecology 层） |
> | Runtime State | 运行时状态不属 WorldQuery |
> | Voxel 真值 | 体素真值不属 WorldQuery（Owner = 世界侧） |
>
> **它只能读取已经存在的解释信息**（已发布/已定稿的产物）。
>
> **编号命名空间（重要）**：本文档使用 **`WQ1`–`WQ120`**，属 **`WorldQuery_Architecture_Contract`**。
> 既有 `WorldQuery_Design.md` 另有 **`WQ1`–`WQ6`**（语义：同一规则 / 只读 / 不反馈生成 / 无副作用 / 无状态）。
> 二者**编号重叠但语义不同**，引用时必须带文档名（见附录 D ⑥）。
>
> **本任务不设计具体 API**：本文档**不定义任何接口名 / 方法名 / 类型名 / 参数签名**（禁止"具体查询函数"式设计），只冻结**架构边界与解释语义**（`WQ109`）。
>
> **必须兼容的上游规范**（本任务已读取，SHA 校验通过；**不得修改**）：
>
> | 规范 | 与本契约的关系 |

>
> **冲突时的优先级**：**查询语义**以 `WorldQuery_Design.md` 为准；**阶段顺序与访问禁令**以 `WorldGeneration_Pipeline_Contract.md` 为准；

> **本契约负责**：WorldQuery 的**定位与边界、输入封闭、结果字段冻结、解释契约、层间解释关系、确定性与局部求值、工具/运行时边界、权限矩阵**。
>
> **零修改声明**：本文档是**声明性文档**，不产生任何运行时效果；开启/关闭本文档**不得改变任何体素输出**（`WQV19`）。

## §1 WorldQuery Position and Boundary

| # | 规则 |
|---|---|
| **WQ1** | **定义**：WorldQuery = **世界解释访问层**：在**不生成、不修改世界**的前提下，为工具/UI/调试/AI/玩家解释系统提供**统一解释查询** |
| **WQ2** | **不生成世界**：不产生任何生成产物（骨架/参数/区域/群系/地质/体素/网格），不触发上游重算 |
| **WQ3** | **不修改世界**：对一切层**零写入**（不写参数、不写 `RegionModifier`、不写 Biome、不写地质判定、不写资源判定、不写体素、不写运行时状态） |
| **WQ4** | **不缓存世界真值**：WorldQuery 不持有任何"真值"；缓存（若实现）只能是**透明缓存**（由 `(Seed, 参数, 世界坐标, 域标签)` 索引、可清空、不改变输出、非权威） |
| **WQ5** | **只提供统一查询接口（语义层）**：统一"**查询目标 + 世界坐标 → 解释结果**"的语义、输入白名单、结果字段与解释要素（不定义符号名，`WQ109`） |
| **WQ6** | **不拥有任何层的产物**（见文首清单：WorldState/Region/Biome/Geology/Resource/Ecology/Runtime State/Voxel 真值） |
| **WQ7** | **只能读取"已经存在的解释信息"**：只读**已发布/已定稿**的产物；不得促使任何层"为了解释而先算"（未定稿一律视为不可读） |
| **WQ8** | **不定义规则**：不得定义阈值、判定链、优先级、噪声；解释必须复用各层既有规则（`WorldQuery_Design.md` `WQ1`/`WQ2`；`PC64` 同构） |
| **WQ9** | **不是生成阶段**：不在 Phase 0–8 的生成链内驱动生成；它是**旁路只读层**（`WorldGeneration_Pipeline_Contract.md` §2 的扩展位，不打断阶段顺序） |
| **WQ10** | **与 Pipeline 的关系**：查询链 = 对生成链的**只读求值**；**不新增 Phase**、不改变 Phase 顺序、不改变任何定稿点（`PC50`） |
| **WQ11** | **与 Runtime 的关系**：Runtime 只能提供**展示上下文**（`WQ21`）与**只读消费**解释；不得改变解释（`WQ86`） |
| **WQ12** | **声明性**：开启/关闭本文档 ⇒ 体素输出逐体素一致（`WQV19`） |

## §2 Input Contract

### 2.1 允许的输入（封闭白名单）

| # | 允许输入 | 说明 |
|---|---|---|
| **WQ13** | **`Seed`** | 世界种子（解释的确定性来源之一） |
| **WQ14** | **World Position** | 世界坐标点（唯一空间自变量；不得以 Chunk/局部坐标为主键，`PC86`） |
| **WQ15** | **已发布 WorldState FinalState** | 8 参数（只读；且必须**已定稿**，`PC21`/`PM61`） |
| **WQ16** | **Biome Identity** | 群系结论（只读；含解释数据） |
| **WQ17** | **Geology Explanation** | 地质解释字段（判定命中、层归属、洞穴倾向、矿藏倾向等；只读） |
| **WQ18** | **Resource Explanation** | 资源判定与依据（只读） |
| **WQ19** | **Ecology Explanation** | 生态候选与资格（只读） |
| **WQ20** | **Voxel Query Result（只读）** | 体素真值查询结果；必须**显式声明真值模式**（规则 / 含编辑，`WQ40`） |
| **WQ21** | **Runtime Context（仅用于展示）** | 运行时上下文；**只允许出现在展示区**，**不得参与生成解释**（`WQ93`） |
| **WQ22** | **输入封闭（全局约束）**：白名单（`WQ13`–`WQ21`）之外的量一律不得读取 | `BC30` 同构；越权读取 = 缺陷 |

### 2.2 禁止的输入（黑名单）

| # | 禁止 |
|---|---|
| **WQ23** | **Player 状态影响生成解释**：玩家的位置/进度/背包/已探索/已采集**不得**参与任何生成层结论的解释（可作为"展示上下文"，但不得进入生成解释） |
| **WQ24** | **Runtime 修改解释结果**：运行时不得改写解释内容、不得让解释随运行时而变化 |
| **WQ25** | **Chunk 决定解释**：不得按 Chunk 划分、按 Chunk 缓存、按加载状态改变解释（`PC79`–`PC84`） |
| **WQ26** | **非权威来源**：**Mesh（几何）不得作为世界真值**；**Debug/工具不得自己重新计算规则**（`PC99`；`PM102`） |

## §3 Query Result Contract

### 3.1 结果字段（冻结，闭合集合）

| # | 字段 | 含义 |
|---|---|---|
| **WQ27** | **Query Target** | 查询目标：本次解释的是"哪个问题/哪个层/哪个结论"（目标必须来自各层已登记的结论类型） |
| **WQ28** | **Current Result** | 当前结论：该目标在该坐标的**已发布**结论（值/分类/判定等级） |
| **WQ29** | **Direct Conditions** | 直接条件：参与判定的**参数值 + 阈值 + 命中/未命中**（可核对，非空泛表述） |
| **WQ30** | **Influencing Layers** | 影响层：哪些层对该结论有贡献（含贡献为 0 的显式说明） |
| **WQ31** | **Excluded Layers** | 排除层：对该结论**无影响**的层与**未命中**的分支 |
| **WQ32** | **Causal Chain** | 因果链：按因果方向从**原因侧**到**结论**的链条（来源/骨架/事件 → 条件 → 结论） |
| **WQ33** | **Why Not Other Results** | 为什么不是其它结果：逐个排除其它候选结论，给出**各自的失败条件**（`BC117` 同构） |

### 3.2 结果硬性规则

| # | 规则 |
|---|---|
| **WQ34** | 结果必须**只读**：不得携带任何写入口、不得诱导调用方修改世界 |
| **WQ35** | 结果必须**确定**：同 `(Seed, Position, 查询目标)` ⇒ 逐字段相同（含字段顺序与解释文本） |
| **WQ36** | 结果**粒度到层与条件为止**：不含对象、物品、掉落、生态内容清单、几何细节（`WE7`） |
| **WQ37** | 结果必须**可分解到层**：能指明"该结论由哪一层、哪条条件产生"（`PC100`）；参数类结论必须能区分 `Base` / `Modifier` / `Final`（`PM100`） |
| **WQ38** | **结果不得成为任何阶段的输入**（防环）：任何生成/判定/运行时逻辑不得读取查询结果（`WQ4`；`PC104`） |
| **WQ39** | 结果**不得包含指令或建议**：只描述"是什么/为什么"，不得给出"应该怎么做"（不得成为生成指令） |
| **WQ40** | 结果必须**标注真值语义**：参数类结论只有**一份真值**（`WSC68`）；体素类结论必须显式声明模式（**规则结果** 或 **含运行时编辑的结果**），不得混用（审查 `AD-2` 仍开放，本契约只要求显式声明） |
| **WQ41** | 结果必须**标注定稿状态**：未定稿/缺失必须显式标记，**不得**把半成品当有效结论返回（`PM33`/`PM61`） |
| **WQ42** | 结果字段是**闭集**（`WQ27`–`WQ33`）：新增字段必须修改本契约并升版本（未登记字段不得出现） |

## §4 Explanation Contract

### 4.1 正确形式（示例，冻结形态）

```
该区域：
  Elevation = X        （值 + 来自哪一层）
  Ocean Influence = Y  （值 / 无影响）
  Temperature = Z      （值 + Base/Modifier 分解）

Biome Classification：
  规则 A 命中（条件：… ；未命中分支：…）

Geology：
  地下密度趋势来自……（判定链命中项）

Resource：
  矿藏存在性来自……（地质基础 + 环境条件 + 纪元）
```

| # | 规则 |
|---|---|
| **WQ43** | 解释必须按**因果方向**组织：`原因 → 条件 → 结论`（`BC118`；`WE2`） |
| **WQ44** | **禁止循环解释**：例如"**这里是森林，因为森林生成了树**"——结论不得作为自身的原因（`C1`/`C2` 同构） |
| **WQ45** | **必须给出条件而非名称**：解释必须落到**参数值/阈值/判定链命中项**，不得以层名/结论名充当解释（`WE6`；`WSC74`） |
| **WQ46** | **解释必须同源**：复用各层既有规则与既有求值路径（`WQ1`/`WQ2`；`PC98`） |
| **WQ47** | **禁止 Debug 另算一套**：任何"近似/简化/独立实现"的解释一律禁止（`PC99`；`PM102`） |
| **WQ48** | 解释必须**只读**：解释不得改变任何层输出、缓存语义或可再次查询性（`WQ5`） |
| **WQ49** | 解释必须**确定**：同一查询点的解释内容与顺序恒定（`WE4`） |
| **WQ50** | 解释必须**可定位到条件**：能指出"哪个条件成立/不成立"（`WE6`） |
| **WQ51** | 解释**粒度到层与条件为止**（`WE7`；`WQ36`） |
| **WQ52** | 解释必须覆盖**每一层的贡献**：无贡献的层必须显式写"无影响"（`WE8`；`PM107`） |
| **WQ53** | 解释必须支持**"为什么没有 X"**：指出"没有候选 / 被前置条件拒绝 / 被上限截断 / 影响不足"中的**具体一条**（`RA109`；`GC131`） |
| **WQ54** | 解释必须支持**"为什么不是别的"**：逐个未命中分支给出失败条件，并解释**有序规则中更早分支为何未命中**（`BC117`） |
| **WQ55** | **禁止由结果反推原因**：不得出现"因为是森林，所以湿润"这类倒因为果解释（`WE3`；`WQ44` 同族） |
| **WQ56** | 解释**不得包含内容清单**：不得列出对象/物品/生物/结构/掉落（`WQ36`） |
| **WQ57** | **展示形式可多样，语义唯一**：文本、结构化数据、可视化必须来自同一份解释语义（不得出现"给人看的版本"与"给机器看的版本"结论不同） |
| **WQ58** | 解释必须**标注其引用的层与契约版本**，便于跨版本对齐与审计（不得隐式引用未登记规则） |

## §5 Layer Explanation Relationship

### 5.1 各层"能解释什么"（冻结职责）

| # | 层 | 可解释内容（唯一来源） |
|---|---|---|
| **WQ59** | **WorldState** | 参数值的 `Base` / `Modifier` / `Final` 分解与来源（`PM100`；`WSC74`） |
| **WQ60** | **Region** | 该点受哪些 Region 影响、各贡献、修正合计（`RA105`/`RA107`/`RA108`） |
| **WQ61** | **Biome** | 群系结论命中的分支、条件、排除分支（`BC112`–`BC117`） |
| **WQ62** | **Geology** | 实体/空（P0–P2）、材料（P3）、洞穴（P1）、矿藏倾向及其依据（`GC127`–`GC134`） |
| **WQ63** | **Resource** | 资源判定的依据（参数 + 地质条件 + 纪元跨度）（`RN8`） |
| **WQ64** | **Ecology** | 生态候选的资格条件与该位置"允许什么"（`EA3`） |

### 5.2 层间关系规则

| # | 规则 |
|---|---|
| **WQ65** | **层间解释必须沿允许链组织**：`WorldState → Region → Biome → Geology → Resource/Ecology → 解释`；不得跳层（`PC62`） |
| **WQ66** | **每层解释只引用其上游**：不得引用下游产物作为依据（`PC60`） |
| **WQ67** | **跨层解释必须显式归属**：每个结论必须标注"由哪一层给出"，不得混合归属 |
| **WQ68** | **不得以下游替代上游**：不得用群系名解释地质（`GC69` 同构）、不得用资源判定解释地质或群系（`RX-1`/`RX-8` 同构） |
| **WQ69** | **解释链必须终止于原因侧**：终止于来源/骨架/历史事实/自然规则；不得以"世界规则"这类空泛表述作为终点 |
| **WQ70** | 层的**解释缺失**必须显式（"该层不可读/未定稿"），不得静默省略（`WQ41`/`WQ52`） |

## §6 Query Determinism and Local Evaluation

| # | 规则 |
|---|---|
| **WQ71** | **同 `(Seed, Position, 查询目标)` ⇒ 同结果**（逐字段；`WA1`/`WE4` 同族） |
| **WQ72** | **反例保护**：不同 `Seed` 或不同显式参数 ⇒ 至少一处解释不同（防恒真断言） |
| **WQ73** | 与**查询顺序 / 遍历顺序**无关（`WL12`） |
| **WQ74** | 与**加载顺序 / Chunk 状态**无关（`WQ25`；`PC87`） |
| **WQ75** | 与**帧序 / tick / 时间**无关（`T1`） |
| **WQ76** | **单点可求值**：任一坐标可独立解释，无需世界级前置（`WL1`；`PCV9`） |
| **WQ77** | **禁止生成整个世界**：不得为回答一个点而全量求值世界（`WL3`） |
