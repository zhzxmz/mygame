# Region Contribution Aggregation Proposal（Phase 3.1.2 · 最小决策方案）

> **文档性质**：**决策方案提案（Decision Proposal）**。把 Phase 3.1.0/3.1.1 两轮审查收敛为**可由设计方直接裁决**的 5 项决策，并给出"枚举 ↔ 合成"之间的接口边界。
>
> **本轮边界（已遵守）**：只读 + 仅新增本文件；**不实现**贡献枚举 / 聚合 / 参数合成；**不修改**任何代码 / 契约 / 测试 / Scene / Prefab / `.meta`；不触碰 `Assets/Scripts/World/V2` 与 Legacy Terrain；**不擅自确定**空间范围、连续性、边界、优先级或数值上限；不改动 6 个 Region Modifier 分量；不新增平行参数计算权威；不重写既有审计报告。
>
> **标签体系（全文只用这四类）**：
> `【契约已冻结】`有条款 + 行号可核 · `【代码现状】`有文件 + 行号可核 · `【推荐方案】`本轮提出、**尚未生效** · `【待裁决】`须由设计方批准或由权威文档升版本。
>
> **一句话提案**：
> **让身份判定保持"单值"，把"单点影响集合"独立为 Region 侧的一个枚举职责；WorldState 侧只负责"调用编排 + 复用既有 `Compose` 合成"。聚合算子不需要新规则（加法 + 钳制已冻结），需要批准的是：上限两项、枚举形式、失败语义、编排归属。**

### 2.5 D4：空集合 `None` 的表示

**原文核对**：`PM32`（**L91**："转发/派生参数的 `Modifier` 必须显式表示为 **`None`**（'不存在修正'，不是'修正为 0'）"）；`WPS58`（**L272**：`Modifier` 以 `0` 承载 = **登记缺口**）；`WPS75`（**L375**：同一缺口的差异登记）；`WSC10`（**L92**：`Elevation`/`Ocean` 不得出现在求和式中）；`WSC14`（**L96**：零修正显式性）；`WSC22`（**L129**：关闭 Region ⇒ `Final == Base`）；`RRD26`（**L96**：修正量 = 恰好 6 分量，字段封闭）。

| 情况 | 语义 | 数值通道（推荐） | 区分通道（推荐） | 状态 |
|---|---|---|---|---|
| **A：没有任何合法贡献** | 该点无任何 Region 影响 | 逐分量 `0`（不得新语义） | 由**解释通道**说明"无影响"（`RA28` L178 要求缺失可解释） | `【推荐方案】` |
| **B：存在贡献，但修正量恰为 0** | 有 Region，但净贡献为 0 | 逐分量 `0`（与 A **数值不可区分**） | 由**枚举结果的成员存在性 + 解释通道**区分（贡献存在但值为 0） | `【推荐方案】` |
| **C：查询 / 枚举失败** | 未取得结果 | **不得**降级为 `0` 后当 A 使用 | 必须是**显式失败信号**（控制流层），不得写入 `Modifier` 数值（字段闭集 `RRD26` L96） | `【待裁决】`（失败语义归属未定） |

| # | 结论 |
|---|---|
| **D4-a** | `【契约已冻结】`：A 必须逐分量 `0`，且与"Region 层不存在"逐值等价（`WSC14` L96、`WSC22` L129、`RM3` L168） |
| **D4-b** | `【推荐方案】`：区分 A / B / C **不得**靠给数值加新语义（会违反 `RRD26` L96 与 `WSC9` L91 的封闭性）；应靠**控制流 + 解释通道** |
| **D4-c** | `【契约已冻结】`：`Elevation` / `Ocean` 的 `Modifier` 应为 `None`（`PM32` L91），且它们**不进入**求和式（`WSC10` L92） |
| **D4-d** | `【待裁决】`：若要把 `None` 做成**类型级**表示（而不是解释/控制流级），必须修改 `RRD`/`PM32` → 需升版本；本轮**不主张**（`WPS58` L272 已登记为缺口） |

## §5 上限数值的确定方法与验收标准（交付内容 5）

| # | 步骤 | 说明 |

| **S-1** | 明确上限语义 | 上限 A = 单点参与叠加/**枚举**的 Region 数量（`RA65` L270 + `RA130` L448 括号内等同）；上限 B = 每大陆每 `DomainId` 的 Region 数量（`RA47` L223） |

| **S-3** | 数值依据的取得方式 | ① 在目标平台上做**基线测量**（单点枚举的耗时/分配随上限 A 的增长曲线）；② 记录"代价与世界 Region 总量无关"的对照数据（`RA128` L446 的验收要求）；③ 记录测量环境（平台/构建/样本集）作为证据 |
