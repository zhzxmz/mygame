## §1 Region Identity 定义

| # | 规则 |
|---|---|
| **RID1** | **定义**：**RegionIdentity = "某个世界坐标点属于哪个世界解释区域"的身份判定结果**（原因侧身份的**只读判定**，不是区域数据、不是修正量） |
| **RID2** | **唯一回答的问题**：Identity 只回答"**这个位置属于哪个世界解释区域**"；不回答"该区域长什么样""该区域修正多少""该位置是什么群系"（`RA17`；`Region_Design.md` §1.1） |
| **RID3** | **`RegionIdentity` ≠ Region 数据**：Identity 是**判定结果**（属于谁），不包含区域自身的字段内容（`Extent` 几何、`ModifierProfile`、`Tags` 内容、`Qualifications` 明细）；区域数据是它的**被引用对象**，不是它本身（`RRD13`/`RRD14`；`RA1`） |
| **RID4** | **`RegionIdentity` ≠ `RegionModifier`**：修正量是**参数空间的量**（6 分量），身份是**空间归属判定**；两者不得互相推导（§6；`RA75`；`RRD26`） |
| **RID5** | **`RegionIdentity` ≠ Biome**：Biome 是**环境表现结论**（结果侧离散分类），Identity 是**原因侧归属**；两者不得互相替换、不得互相推导（`RA92`；`RTY5`；`RRD6`；`RAB11`） |
| **RID6** | **`RegionIdentity` ≠ Chunk**：Chunk 是**技术划分**（加载/管理单位）；Identity 不得按 Chunk 划分、存储或对齐，也不得依赖"Chunk 是否加载/已生成"（`RA93`/`RA94`/`RA96`；`RRD5`；`RAB15`） |
| **RID7** | **`RegionIdentity` ≠ 参数或参数向量**：身份不由参数值定义、不由参数值反推、不写入任何参数（`RA4`；`RAB16`；`RRD36`/`RRD37`） |
| **RID8** | **`RegionIdentity` ≠ 产出物/实体**：身份**不表示**"已生成对象/结构/植被/生物"，也不保证"该处已生成任何内容"（`RA8`；`RGS`；`RAB13`） |
| **RID9** | **Identity 必须可解释**：必须能回答"为什么该位置属于该区域"（来源与理由链），且解释只读（`RA28`；`RA82`；`RA83`） |
| **RID10** | **Identity 是只读发布信息**：任何下游系统不得创建、修改或删除身份；身份不得作为任何写入路径的输入（`RA20`；`RA110`；`RRD71`） |

## §2 输入契约

### 2.1 唯一输入

| # | 规则 |
|---|---|
| **RID11** | **唯一输入**：`WorldSeed` + `WorldCoordinate`。二者构成**完整且封闭**的输入集合（`D1`；`RA115`；`PM51`） |
| **RID12** | `WorldSeed` 为只读整数种子值；判定不得写入、不得派生第二套种子语义（`PZ1`；`RA115`） |
| **RID13** | `WorldCoordinate` 为**世界体素坐标**（整数三元组），是**唯一空间输入**；坐标换算必须复用既有 VoxelCore 坐标契约，**不得**引入第二套坐标语义、不得使用 Chunk 局部坐标（`D1`；`DR17`；`RRD60`；`RABW2`） |
| **RID14** | **允许读取（Phase 1 参数白名单口径）**：仅允许读取 Phase 1 已冻结的允许读取面（`D4`；`DR21`）：既有 VoxelCore 坐标/体素契约（只读）、已登记的显式配置（`WorldGenerationSettings` 中的已登记项）、只读高度场；且这些量**本身必须是 `(Seed, Coordinate)` 的函数**（`RABW5`；`RID30`） |
| **RID15** | **参数读取约束**：若判定需要读取参数类量，只允许读取**已定稿的 Base 级/地形派生量**（`Elevation`/`Ocean`，只读）；**禁止**读取 `FinalState`（未定稿，读它构成环）（`RAB19`；`RAB32`；`RRD33`） |
| **RID16** | **白名单权威**：输入白名单的权威是 `Region_Architecture_Boundary_Contract.md` §3.1（`RABW1`–`RABW7`）与 `WorldParameter_Source_Contract.md` §6.1（`WPSW1`–`WPSW7`）；本契约**不复制、不新增、不放宽**（`RAB31`） |

### 2.2 禁止输入

| # | 禁止读取 | 依据 |
|---|---|---|
| **RID17** | **Chunk**：Chunk 编号、局部坐标、生命周期、是否已加载/已生成、Chunk 划分 | `RA93`/`RA96`；`RABB10`；`RRD60` |
| **RID18** | **Scene**：场景对象、`Transform`、相机、渲染状态 | `DR18`；`RABB11` |
| **RID19** | **Player**：位置、进度、背包、已探索、已采集 | `RA121`；`PZ7`；`RABB2` |
| **RID20** | **Runtime**：脏标记、加载集合、预算、帧序、调度状态、已生成内容 | `RABB1`；`PX2`；`PM55` |
| **RID21** | **Entity**：任何对象/结构/生物/实体状态 | `RA8`；`EF1`；`RABB3` |
| **RID22** | **Mesh**：几何、面、材质、子网格 | `RABB4`；`Region_Design.md` §12.3 |
| **RID23** | **Voxel 修改结果**：玩家编辑后的体素真值、体素状态、材料 | `RABB6`；`RA99` |
| **RID24** | **输入封闭**：上述禁令是**整体性**的，任一命中即判违规 | `RABB1`–`RABB18` 为黑名单权威；不得以"只读一次/仅调试/不影响结果"豁免（`RAB31`/`RAB36`；`RAB37`） |

## §3 Determination Boundary

### 3.1 定义与输出

| # | 规则 |
|---|---|
| **RID25** | **定义**：**Region Determination = 函数 `(WorldSeed, WorldCoordinate) → RegionIdentity`**；本文档只定义其**边界**，**不定义任何算法**（`RA1`；`RAB5`） |
| **RID26** | **输出**：给定一个世界坐标，输出该点的 **`RegionIdentity`**（身份判定结果）；**不输出** Region 全量数据、不输出 `RegionModifier`、不输出任何下游结论（`RAB-O1`；`RRD61`） |
| **RID27** | **判定不等于采纳**：Determination 是**只读判定（读路径）**；采纳（`RA31`–`RA58` 同族）是**候选 → Region 的建立流程（写路径）**。二者不得互相替代、不得合并为"判定时顺手创建 Region"（`RRD62`；`RAX-13`） |
| **RID28** | **不实现**：本文档不定义划分算法、生成算法、噪声、Voronoi、形状函数、阈值或任何数值（`RA145`；`RAB94`） |

### 3.2 确定性与禁止事项

| # | 规则 |
|---|---|
| **RID29** | **核心等式**：**Same Seed + Same Coordinate = Same Identity**（逐字段）（`RA115`；`PM52`；`RRD73`） |
| **RID30** | **纯函数**：判定不得依赖任何外部状态；同输入必须恒等（`WSC23`；`PZ2`；`RA16`） |
| **RID31** | **可重复**：多次调用、两个独立实例/进程、任意遍历顺序 ⇒ 逐字段相同（`RAV3`；`RAV4`） |
| **RID32** | **无副作用**：不写任何状态、不建 Chunk、不置脏、不生成对象或 Mesh（`WSC20`；`T4`；`RA97`） |
| **RID33** | **禁止时间**：`Time` / `DateTime` / 时间戳 / 真实时长 / tick / 帧序 / `Guid`（`RA120`；`PZ6`） |
| **RID34** | **禁止随机状态**：`Random` / 任何有状态伪随机源（`RA119`；`PZ5`） |
| **RID35** | **禁止加载顺序**：加载/卸载顺序、遍历顺序、查询顺序、世界级中间态（`RA122`；`PZ4`/`PZ8`） |
| **RID36** | **禁止对象实例状态**：不得依赖任何跨帧对象、缓存对象、Region 实例、World 实例的存在、身份或状态（`RA16`；`RA137`；`PM49`） |
| **RID37** | **禁止下游反推**：不得由 `RegionType`/Biome/生态/资源/体素结果反推身份（`RA123`；`RA79`；`PZ9`） |
| **RID38** | **局部性与域**：单点判定必须能独立完成、不依赖世界级前置（`RA127`/`RA128`）；若使用域，必须使用 §6.4 已登记域且**域参与哈希混合**（`RA116`/`RA117`；`PZ11`/`PZ12`） |

## §4 Identity 字段

### 4.1 逻辑字段（只定义语义，不定义数据结构）

| # | 逻辑字段 | 语义 | 硬性约束 |
|---|---|---|---|
| **RID39** | **原则** | 本节只定义**逻辑字段**（存在性 / 语义 / 只读性） | 不定义数据结构、几何、内存布局、存储位置、序列化（`RRD13`；`B-3` 保持未决） |
| **RID40** | `RegionId` | 该区域的稳定标识（由 `RegionKey` 派生的可读/可比标识） | 仅用于标识、调试、解释输出；**不得**作规则输入、**不得**作排序/截断键（`RA15`；`RRD17`） |
| **RID41** | `RegionDomain` | 该区域所属的**已登记域** | 未登记域**不得使用**；域必须来自 §6.4 的 Region 域分配（`RA10`；`RA116`；`PZ10`） |
| **RID42** | `RegionSource` | 该区域的原因来源引用（来源类别 + 原因引用链） | 只读；来源类别清单权威 = `Region_Design.md` §3.2（**不复制、不新增**）；必须满足"无源不成区"（`RG-A`；`RA26`；`RRD22`） |
| **RID43** | `RegionExtentReference` | 该区域**空间范围的引用**（锚点 + 尺度 + 衰减形状**标识**） | **只是引用**，不是几何/包围盒/体素范围；必须紧支撑、单调不增、边界连续趋于 0（`RA72`；`RBD1`/`RBD3`；`RRD19`） |
| **RID44** | `解释标签` | 解释用派生标签（`RegionType`）与只读标签（`Tags`） | **无规则权**：不得参与判定、采纳、排序、上限、修正；只能用于解释/调试/工具（`RA85`–`RA90`；`RRD23`） |

## §5 空间连续性登记

> **本节性质**：**只登记设计问题**——不裁决、不定义算法、不定义形状、不给出阈值（`RID28`；`RAB5`）。

### 5.1 已有契约结论（无需裁决，仅登记以免误读）

| # | 已冻结结论 | 依据 |
|---|---|---|
| **RID53** | **多区域重叠是允许的、且必须支持**：一个点可同时受多个 Region 影响，修正为逐分量加法叠加（交换律），不得引入覆盖/优先级/胜负语义 | `RA63`；`RA66`；`RA71`；`Region_Design.md` §9 |
| **RID54** | **单区域贡献形状有硬性要求**：紧支撑（超出半径恒为 0）、随距离单调不增、边界连续趋于 0 | `RA72`；`RBD1`/`RBD3` |
| **RID55** | **区域边界与 Chunk 无关**：不得与 Chunk 边界对齐、不得依赖 Chunk 尺寸、不得按 Chunk 组织 | `RA94`；`RA93`；`RAB15` |
| **RID56** | **退化等价**：关闭 Region 层 ⇒ `Final == Base`（逐分量）且输出逐体素一致 | `RA104`；`RI3`；`WSC22`；`RRD41` |

### 5.2 未决设计问题（**只登记，不裁决**）

| # | 未决问题 | 现状（未定义部分） |
|---|---|---|
| **RID57** | **Q1 连续性**：一个 Region 的空间范围是否必须**连通**（不允许分片），还是允许同一身份对应多个不连通片段？ | 既有契约未定义 `Extent` 的连通性要求（`RA72` 只约束贡献形状，不约束连通性） |
| **RID58** | **Q2 边界突变**：允许"影响量为 0 但归属仍成立"这种**不连续跃变**吗？"属于该区域"的判定函数是否必须连续？ | 既有契约只要求**贡献函数**边界连续趋于 0（`RA72`），未定义**归属判定**的连续性 |

| **RID61** | **Q5 锚点与范围的关系**：锚点是否必须位于区域内部？`CanonicalPosition` 量化（`RA12`）与范围形状的关系是什么？ | 量化规则已登记（`RA12`），但"锚点是否必须在范围内"未定义 |

| **RID64** | **登记纪律**：上述问题**不得**在实现中被单方面裁决；任何裁决必须先由权威文档升版本或由决策记录裁决 | `RRD102` 同族纪律；`RAB81` |

| **RID66** | **不得以本契约的登记代替裁决**：本节条目的存在**不构成**对任何设计问题的答案，也不得被引用为"已决定" | `RID28`；`RID64` |

## §6 与 `RegionContext` 的关系

### 6.1 单向链

| # | 规则 |
|---|---|
| **RID67** | **唯一方向**：`Identity → Context → Modifier`（逐级派生，方向唯一，不得反向）（`RG-B`；`RRD14`） |
| **RID68** | **Identity 是 Context 的输入**：`RegionContext` 的"身份信息"字段**引用** Identity，不得改写身份（`RRD21`；`RID10`） |
| **RID69** | **Context 是解释层**：Context 提供来源解释、标签、只读引用与资格声明；Modifier 的 6 分量由 Region 层提供，其解释经 Context 暴露（`RRD22`–`RRD27`；`RA75`） |
| **RID70** | **Modifier 是链的末端产物**：Modifier 只提供**修正项**，不提供身份、不提供上下文、不提供解释（`RAB9`；`RRD26`） |

### 6.2 反向禁令

| # | 规则 |
|---|---|
| **RID71** | **禁止 `Modifier → Identity`**：不得由修正量反推身份（含"因为魔力高所以属于魔法区域"这类反推）（`RA79`；`RA123`；`RAB28`；`PZ9`；`RRD83`） |
| **RID72** | **禁止 `Context → Identity`**：不得由标签/资格/解释内容反推或改写身份（`RA85`/`RA89`；`RA82`） |
| **RID73** | **禁止下游反推身份**：不得由 `FinalState` / Biome / 生态 / 资源 / 体素结果反推身份（`PZ9`；`RA7`；`RA110`） |
| **RID74** | **禁止用身份参与修正计算**：身份是**归属判定**，不得作为修正量的输入，也不得用身份替代来源（`RA2`；`RA86`；`RA87`） |
| **RID75** | **解释链必须可追溯**：`Identity → Context` 的解释必须只读、确定性、可回答"为什么"（`RA26`/`RA28`；`RA83`） |
| **RID76** | **本契约不定义 Context/Modifier 的内部字段**：其字段边界与状态归 `Region_Runtime_Data_Contract.md`（`RRD21`–`RRD27`、`RRD43`–`RRD47`） |

## §7 Legacy 隔离

| # | 规则 |
|---|---|
| **RID77** | **完全隔离（双向）**：身份判定不得依赖 Legacy 任何类型/产物；Legacy 也不得依赖 Region 身份（`RAB83`；`RRD85`） |
| **RID78** | **禁止 `TerrainChunk` 坐标**：不得使用 Legacy 的 Chunk 局部坐标与坐标迁移语义；身份判定只接受世界坐标（`RAB-L3`；`RID13`） |
| **RID79** | **禁止 `ChunkSpace`**：不得引用或镜像 Legacy 坐标空间类型（`RAB-L2`） |
| **RID80** | **禁止 `DensityTerrain`**：不得读取、调用、镜像 Legacy 地形/密度实现（`RAB-L2`；`RRD86`） |
| **RID81** | **禁止 `TerrainMining`**：不得读取挖掘状态、开采进度或已采集统计（`RAB-L4`；`RABB5`；`RID23`） |
| **RID82** | **禁止任何 Legacy Terrain 类型与产物**：含 Legacy 网格/运行时突变结果与其语义借用（`RAB-L1`/`RAB-L2`/`RAB-L5`；`RAB85`） |
| **RID83** | **可机械验证**：结构扫描中 Legacy 符号命中必须为 **0**；Legacy 基线 SHA 必须保持不变（`RAB86`；`RV9`；`Legacy_Status.md`） |
| **RID84** | **实现位置**：身份判定的实现只能落在 V2 侧；不得写入 Legacy 目录，也不得改写受 SHA 冻结的既有实现（`RAB84`；`RV10`） |
