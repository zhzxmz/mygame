# RegionSourceCandidate Field Freeze Matrix（Phase 3.1.8 · M-1 字段冻结准备）

> **文档性质**：**字段冻结准备（Field Freeze Preparation）**。对 8 个概念字段逐项判断"C# 存储类型是否已有足够依据确定"，并区分**四层**（概念 / 存储类型 / 值域与有效性 / 引用解析或运行时语义）。
>
> **本轮边界（已遵守）**：不修改任何契约 / 设计文档 / 决策记录 / 历史报告；不修改任何 `.cs` / `.meta` / 测试 / 场景 / Prefab / ScriptableObject；**不实现** `RegionSourceCandidate`；**不新增**枚举 / 注册表 / 接口 / 方法 / 候选生成 / 空间查询 / 枚举算法；不确定上限 A/B；不设计截断策略；**不解决** `RA22` 半径归属；**不裁定** `RID57`–`RID63`；不把 `Radius` 字段裁决扩大为空间语义裁决；不把推断写成原文事实。
>
> **状态定义（本文件专用）**：
> **`已可冻结`** = 存储类型与表示可由契约明文或既有同概念代码先例直接确定，**无需新的设计决策**；
> **`有条件可冻结`** = 选项已收敛（1–2 个），只需设计者**一次批准**，且**不涉及新语义**；
> **`阻塞`** = 缺少必要输入（字段**内部结构**或值域本身未定），批准前无法写出类型。
>
> **证据等级（本文件专用）**：`【原文事实】`（条款 + 行号可核）· `【证据支持的推断】`（由多处原文交叉推出，非明文）· `【设计建议】`（本轮提出、未生效）。
>
> **一句话结论**：**8 个字段中：1 个已可冻结（`DomainId`）、6 个有条件可冻结（一次批准即可）、1 个阻塞（`Epoch` 槽位的内部结构）；因此"纯数据载体"当前尚不能实现，但硬阻塞只有 1 项。**
