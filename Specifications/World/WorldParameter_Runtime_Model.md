> **仅创建 Markdown**；**不修改任何代码**；**不创建 `.cs`**；**不修改任何已有规范**；**不新增参数**；**不新增 `VoxelType`**。
>
> **本文档不是实现**。**不定义**：数值、阈值、生成算法、噪声公式；**只定义数据结构语义**。
>
> **核心定位**：

## §1 Position and Boundary

| # | 规则 |
|---|---|
| **PM1** | **定义**：WorldParameter Runtime Model = **"已经计算完成的世界参数状态"**的表示契约（状态怎么表示、怎么被只读访问、生命周期多长、谁能读） |
| **PM2** | **≠ Generator**：本模型不产生参数、不参与参数求值；不定义任何生成算法（§11） |
| **PM3** | **≠ WorldState Generator**：本模型不做 `Base + Modifier` 的**求值过程**，不做钳制；它只表示**已完成**的结果（合成权归 WorldState 层，`RA76`/`PC20`） |
| **PM4** | **责任（三项，唯一）**：① **表示/持有** `FinalState`（含 `Base` 与 `Modifier` 的可分解表示）；② **提供只读访问**；③ **支持局部查询**（按世界坐标） |
| **PM5** | **禁止（三项）**：① **修改参数**（任何字段、任何时刻）；② **生成参数**（不得实现求值/合成）；③ **保存 Runtime 状态**（玩家、加载、脏标记、编辑记录） |
| **PM6** | **不拥有规则**：本模型不定义阈值/噪声/规则表；每层规则的权威仍是各层规范（继承 `PT1`；`PC6` 同构） |
| **PM7** | **"保存"语义澄清（重要）**：本模型中的"保存"= **内存中的表示/持有**（presentation），**不是持久化存档**；参数可由 `(Seed, Domain, Position)` 纯函数重算，**不需要存档**（`PC78`；`WorldParameter_Contract.md` §9.2 第 6 项；附录 D ①） |
| **PM8** | 本模型**不定义**：参数具体数值、阈值、生成算法、噪声公式；也不定义参数的**具体列表**（列表权威 = `WorldParameter_Contract.md` 附录 B） |
| **PM9** | **声明性**：本模型的存在/缺失不得改变任何生成结果或体素输出（`PMV19`） |
| **PM10** | **唯一权威表**：本模型的**数据形态与访问语义**归本文档；参数语义归 `WorldState_Design.md`；参数身份/权限归 `WorldParameter_Contract.md`；修正写入权归 `Region_Architecture_Contract.md` |

## §2 Parameter Identity Contract

| # | 规则 |
|---|---|
| **PM11** | **每个参数必须具有六元身份**：**唯一 ID** · **类型** · **单位** · **数值范围** · **来源（Owner/Producer）** · **生命周期** |
| **PM12** | **`ParameterId` 语义**：`ParameterId` 是**稳定的整数标识**（`int`），用于索引、比较、序列化主键与结构布局；其**分配表**的权威是 `WorldParameter_Contract.md` **附录 B**（本模型**不新增**、不改号） |
| **PM13** | **禁止以字符串作为唯一标识**：形如 `"temperature"` 的字符串**只能作为人类可读别名**，不得作为访问键、索引、序列化主键或比较键 |
| **PM14** | **别名规则**：名称/缩写/本地化文案仅用于文档、日志、解释输出与工具展示；**任何访问路径必须经 `ParameterId`** |
| **PM15** | **ID 稳定性**：`ParameterId` 一经发布**不得重命名、不得改号、不得复用**；若必须变更，须在契约层升版本并提供**映射表**（`PC16` 同构） |
| **PM16** | **类型/单位/范围**的唯一权威是 `WorldParameter_Contract.md` §5.2（范围冻结表）；本模型不得另行解释（禁止"同一参数两套范围"，`PW3`） |
| **PM17** | **来源**（Owner / Producer）的唯一权威是 `WorldParameter_Contract.md` §4 权限矩阵；本模型不改变归属 |
| **PM18** | **生命周期**必须与 `ParameterId` 绑定，并按 §6 冻结（World / Generation / Query / Runtime 四层） |
| **PM19** | **身份集合封闭**：未登记的 `ParameterId` **不得使用**（`PT8`："未登记即禁止"） |
| **PM20** | **身份必须编译期可知**：参数集合是**固定、有限、显式**的；**禁止动态注册/运行时增删参数**（`PM46`） |
| **PM21** | 身份元数据**不得依赖运行时状态**（不得由加载/玩家/帧序改变） |
| **PM22** | 身份元数据对**所有消费者只读**（所有列 `R`；无写权限） |

## §3 Parameter State Contract

### 3.1 WorldParameterState 的组成（三态）

| # | 规则 |
|---|---|
| **PM23** | **`WorldParameterState` 必须包含三态**：**`BaseValue`**（基础值）· **`Modifier`**（修正项）· **`FinalValue`**（最终值） |
| **PM24** | **关系（唯一）**：`FinalValue = Evaluate(BaseValue + Modifier)` |
| **PM25** | `Evaluate` 的**语义**：按契约范围**钳制**（连续量 `[0,1]`；`Balance` `[-1,1]`；`Elevation` 整数；`Ocean` 布尔）；**不含任何算法定义**（算法归实现规范） |
| **PM26** | **三态必须同源可分解**：任一参数必须能同时给出 `BaseValue`、各来源贡献、`Modifier` 合计与 `FinalValue`，且满足 `Σ 贡献 == Modifier`、`Evaluate(Base + Modifier) == Final`（供 §9 解释） |
| **PM27** | **`BaseValue` 可独立求值**：不依赖任何 Region 即可得到（WorldState 侧定义性要求） |
| **PM28** | **`Modifier` 的唯一写入者是 Region 层**（`RA75`）；本模型**只持有**、不改写 |
| **PM29** | **`FinalValue` 由 WorldState 层合成**（`RA76`/`PC20`）；本模型不参与合成 |
| **PM30** | **禁止 Runtime 修改**：Runtime 对三态只有只读权限（`PX2`；§6/§8） |

### 3.2 状态闭集与不变量

| # | 规则 |
|---|---|
| **PM31** | **状态字段闭集**：`{ParameterId, BaseValue, Modifier, FinalValue, 来源引用}`；**不得**携带额外内容（不得塞入 Biome/生态/资源/体素/对象信息） |
| **PM32** | **转发/派生参数的表示**：`Elevation` / `Ocean` 的 `Modifier` 必须显式表示为 **`None`**（"不存在修正"，不是"修正为 0"）；`Balance` 以**派生只读视图**呈现（不得被任何修正写入） |
| **PM33** | **禁止"部分填充"**：状态要么**完整**（三态齐备），要么以**显式缺失标记**表达未定稿（不得返回半成品被下游当有效值使用） |
| **PM34** | **状态不可变**：构造/发布后即**只读定稿**（`PC50`）；任何"原地更新"一律禁止（更新只能产生**新的定稿版本**，见 §8 的禁令） |
| **PM35** | 状态**不得携带下游产物**：不得包含 Biome 结论、生态候选、资源判定、体素值、网格数据 |
| **PM36** | 状态**不得作为权威缓存**：若存在缓存，必须是**透明缓存**（由 `(Seed, 参数, 世界坐标, 域标签)` 索引、可清空、不改变输出、非权威，`RA138`） |

## §4 Storage Model Boundary

### 4.1 三种候选的比较（冻结选择）

| 候选 | 形态 | 优点 | 风险 |
|---|---|---|---|
| **A. 固定字段模型** | 每个参数一个具名字段（`TemperatureBase`, `TemperatureModifier`, `TemperatureFinal`, …） | 无查找开销；类型明确；编译期完备 | 参数增多时结构膨胀；易出现"字段重复/漏同步" |
| **B. 枚举索引模型** | 以 `ParameterId` 为下标的**定长**数组/表（每个 `Id` 对应三态） | **确定性**（无哈希、无字符串、顺序固定）；批量遍历稳定；与"参数集合封闭"天然契合 | 需要显式 ID 分配与边界校验 |
| **C. 只读表模型** | 对外暴露**只读视图/表**（消费者只能按 ID 检索） | 权限天然只读；便于解释与工具 | 若作为**唯一**形态则缺少写入侧与编译期完备性 |

### 4.2 V1 选择与硬性规则

| # | 规则 |
|---|---|
| **PM37** | **V1 选择：B（枚举索引模型）为权威数据模型** |
| **PM38** | **A（固定字段）是 B 的一种合法物理布局**：允许实现以具名字段承载，但**语义仍以 `ParameterId` 索引为准**（不得因布局改变可见行为） |
| **PM39** | **C（只读表）是 B 的发布/消费视图**：消费者只通过**只读视图**访问；视图不得提供写入口 |
| **PM40** | **禁止 `Dictionary` / `HashMap` 等哈希容器作为唯一架构基础**（原因：**需要确定性**——哈希遍历/实现顺序会污染结果与解释输出） |
| **PM41** | 若实现使用哈希容器，只能作为**透明缓存**（`PM36`），且**不得**：作为唯一真值、作为遍历来源、影响任何输出顺序 |
| **PM42** | **禁止字符串键**作为主索引（`PM13`/`PM14`） |
| **PM43** | **禁止把无序容器的遍历顺序暴露给消费者**：任何"按遍历顺序输出/比较/截断"的行为一律禁止 |
| **PM44** | **确定性要求**：状态的内容与顺序必须与容器实现无关（同 `(Seed, 坐标)` ⇒ 逐字段相同，`PMV6`） |
| **PM45** | **存储不得引入动态增删**：参数集合固定、定长、编译期可知（`PM20`） |
| **PM46** | **定长索引**：索引范围由 `ParameterId` 分配表决定；越界 ID 必须被拒绝（不得静默扩展） |
| **PM47** | **存储优化（内存布局/压缩/SIMD/SoA 等）不属于 V1 范围**（§11） |
| **PM48** | 缓存（若实现）必须**透明、可清空、非权威、非第二真值**（`PM36`/`RA138`） |
| **PM49** | 存储**不得跨帧存活**为"世界状态"；不得要求"世界实例"存活（`PC77`） |
| **PM50** | **存储模型不得改变任何生成结果**：开启/关闭任何存储形态 ⇒ 体素输出逐体素一致（`PMV19`） |

## §5 Coordinate Evaluation Contract

### 5.1 查询语义

| 项 | 内容 |
|---|---|
| **Input** | **World Position**（世界坐标点；水平方向不设边界，垂直方向按 `WorldHeight` 约束） |
| **Output** | **Parameter State**（§3 的三态表示，含身份引用） |

| # | 规则 |
|---|---|
| **PM51** | 查询必须**只以世界坐标为自变量**（外加 `Seed` 与显式参数）；不得以 Chunk/局部坐标为主键（`PC86`） |
| **PM52** | **同坐标 + 同 `Seed` ⇒ 同结果**（逐字段，含 `Base`/`Modifier`/`Final`）（`WS1`；`BC34` 同构） |
| **PM53** | 查询必须**纯函数且无副作用**：不写状态、不建 Chunk、不置脏、不生成对象（`T4`） |
| **PM54** | **禁止依赖 Chunk**：不得要求"该 Chunk 已加载/已生成"（`PC87`；`WL8`） |
| **PM55** | **禁止依赖 Runtime**：不得读脏标记/加载集合/预算/帧序（`PC4`/`PX4`） |
| **PM56** | **禁止依赖 Player**：不得读玩家位置/进度/背包/已探索（`PZ7`/`WSC58`） |
| **PM57** | **禁止依赖 Entity**：不得读任何对象/结构/生物状态（`EF1`/`ADR-001`） |

### 5.2 单点求值与真值语义

| # | 规则 |
|---|---|
| **PM58** | **单点可求值**：任一世界坐标可独立求出完整状态，不需要任何世界级前置（`PCV9`；`WL4`） |
| **PM59** | **不要求"世界实例"存活**：连续两次查询之间不需要跨帧状态（`PC77`） |
| **PM60** | **真值语义必须显式**：本模型表示的是**唯一一份**参数真值（`Base + Modifier`）；**不存在"玩家编辑后的参数版本"**（`WSC68`；附录 D ④） |
| **PM61** | **未定稿不得返回**：`FinalValue` 只能在 Phase 3 完成之后可读（`PC19`/`PC21`/`PC50`）；在此之前只允许读 `BaseValue`（且必须显式标记为"未定稿"） |
| **PM62** | 查询**不得改变状态**：查询前后三态逐字段不变（`RAV19` 同构；`PMV12`） |

## §6 Lifecycle Contract

### 6.1 四层生命周期（冻结）

| # | 生命周期 | 覆盖数据 | 规则 |
|---|---|---|---|
| **PM63** | **World Lifetime** | `Seed`、`Skeleton` | 与"世界"同寿；可由种子 + 坐标 + 显式参数**重算**；**不需要存档**（`PC67`） |
| **PM64** | **Generation Lifetime** | **Base Parameter**、**Modifier** | 生成期数据；由规则确定；**可重算、可丢弃**；不得被 Runtime 修改 |
| **PM65** | **Query Lifetime** | **FinalState** | **派生视图**（`Base + Modifier` 的定稿结果）；按需生成、可丢弃、可重建；**不是持久化数据** |
| **PM66** | **Runtime Lifetime** | 对参数的**只读引用** | Runtime 只持有**只读引用**；不得持有可变句柄、不得写回 |

### 6.2 硬性规则

| # | 规则 |
|---|---|
| **PM67** | **禁止 Runtime 修改 Parameter**（`PX2`；`PM30`） |
| **PM68** | **生命周期派生关系**：`Query Lifetime` 由 `Generation Lifetime` 派生；`Generation Lifetime` 由 `World Lifetime`（+ 显式参数）派生；**派生方向不可逆** |
| **PM69** | 长生命周期数据**不得引用**短生命周期数据（World 不得持有 Chunk/Query 引用） |
| **PM70** | **短生命周期结束不得改变结果**：丢弃 `FinalState` / 缓存后重算必须逐字段相同（`PC75`） |
| **PM71** | 参数**不需要存档**；存档边界只覆盖 `Runtime Lifetime` 的运行时数据（`PC78`） |
| **PM72** | **无跨帧状态**：本模型不定义"上一次查询结果"作为世界状态（`PC77`；§8） |
| **PM73** | **无版本链**：不得保存"旧参数版本/快照序列"（§8） |
| **PM74** | **生命周期 ↔ Phase 对应**：Phase 0/1 → `World Lifetime`；Phase 2/3 → `Generation Lifetime`（Base / Modifier）；Phase 4 起 → `Query Lifetime`（FinalState 的只读消费） |
| **PM75** | **引用不得延长生命周期**：Runtime 的只读引用不得使参数数据变成 Runtime State（反之亦然） |
| **PM76** | **与 Pipeline §4 的口径映射（细化，非冲突）**：本模型的 `World/Generation/Query/Runtime` 是 `WorldGeneration_Pipeline_Contract.md` §4 生命周期在**参数数据**上的细分（见附录 D ②） |

## §7 Consumer Contract

### 7.1 消费者读取集（封闭）

| # | 消费者 | 允许读取（Read） | 写入（Write） |
|---|---|---|---|
| **PM77** | **Biome** | **仅 `FinalValue`**（8 参数，只读）；**禁止**读 `Modifier` 原始分量与 `RegionType`（`BC27`/`BC30`） | **禁止全部写** |
| **PM78** | **Geology** | **不读参数**（`GC25`/`GC75`）；参数只能经 Biome 的 **P3** 进入（`GC71`/`GC72`） | **禁止全部写** |
| **PM79** | **Ecology** | `FinalValue`（参数白名单，只读）+ Region 只读标签（`EA2`） | **禁止全部写**（`E-3`） |

| **PM81** | **WorldQuery** | `BaseValue` / `Modifier` / `FinalValue`（**仅解释用**，只读） | **禁止全部写**（`WQ4`；`RA110`） |

## §8 Parameter Version Contract

| # | 规则 |

| **PM89** | **禁止系统保存"旧参数版本"**：任何"上一帧/上一次查询的参数值"不得被保存或参与判定 |
